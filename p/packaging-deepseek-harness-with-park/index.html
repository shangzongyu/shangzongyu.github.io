使用 Park 打包 DeepSeek Harness 为桌面端

shangzongyu 收录于 工具
 2026-08-16  约 245 字   预计阅读 1 分钟 
目录

20260813 DeepSeek Harness 发布，当天没有尝试，等第二天到公司事情不多，我就想想着试试看看效果如何，就参考官方文档是红 npx 启动了 DeepSeek Harnnes，一切都顺利，但是启动后没有想到用它来做什么。

吃饭的时候突然想到作为一个程序员，使用 npx 很容易，那么普通用户呢，他们该如何使用这个，我想想到了我之前接触的工具 Pake，可以使用这个工具来把 Web 界面的大包为桌面版，这样普通用户就能使用了。

我自己对 Pake 不熟悉，这个任务该如何实现，DeepSeek Harnnes 刚好通过这个这个任务试试。

这个 https://github.com/shangzongyu/deepseek-harness-desktop 地址就是我的成果，可以在 Release 中下载 macOS M 芯片的桌面版。
