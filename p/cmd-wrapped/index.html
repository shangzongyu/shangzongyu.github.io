查看 Shell 历史记录。

介绍

使用 Rust 实现的用户查看自己命令行的使用。

安装

Github：https://github.com/YiNNx/cmd-wrapped

# 使用 cargo
cargo install cmd-wrapped

# Arch Linux
yay -S cmd-wrapped

# 自己编译使用
git clone git@github.com:YiNNx/cmd-wrapped.git
cd cmd-wrapped

## 生成 2023年
cargo run -- 2023
## 或者
./target/debug/cmd-wrapped 2023
