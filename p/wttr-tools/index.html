工具推荐: wttr - 命令行查询天气

shangzongyu
 2022-07-12  约 3379 字   预计阅读 7 分钟 
目录

wttr.in 用于在命令行查询天气

# 使用方法
curl wttr.in/你要查询的城市

# 例如查询深圳天气
curl wttr.in/shenzhen

# 想以中文方式显示的话只要改为
curl zh.wttr.in

# 例如查询深圳天气
curl zh.wttr.in/shenzhen

# 更多使用方法可以输入
curl wttr.in/:help

示例：
