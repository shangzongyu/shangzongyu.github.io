- 官网：<https://t3.codes/>

T3 Code 是个开源的 AI 编程工具，能把 Codex 和 Claude Code 放到同一个界面里，用的还是你原来的账号。比如一个对话让 Codex 改代码，另一个让 Claude Code 看看报错是怎么来的。两边可以同时跑，改了哪些文件也能直接在对话里看。

最近在使用的工具，现在基本上已经替代了 ChatGPT 了，而且我认为 T3 Code 的手机体验比 ChatGPT 好多了。

手机连上电脑之后，电脑上开的对话可以接着聊。出门前丢个任务给它，路上想起来还漏了一句，拿手机补上就行。
