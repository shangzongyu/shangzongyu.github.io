记录一下 2026 年我用过的工具。这里既有长期使用的，也有最近正在体验的，评价都比较主观。

<!--more-->

## 终端

### cmux

- 官网：<https://cmux.com/>
- GitHub：<https://github.com/manaflow-ai/cmux>
- 介绍：基于 [Ghostty](https://ghostty.org/) 渲染引擎的原生 macOS 终端，主要解决 Ghostty 没有垂直标签页的问题。

> 使用体验：速度还行，就是太丑了。

人们那么喜欢 cmux，其实就是喜欢垂直标签页和内置浏览器。等等，这不就是 [Cursor](https://cursor.com/) 吗？只是性能更好，没有 IDE 的累赘，还可以搭配任意模型和 Agent 使用。

几个方向相近的项目：

- Linux：[limux](https://github.com/am-will/limux)
- Windows：[cmux-windows](https://github.com/mkurman/cmux-windows)
- macOS：[Mori](https://github.com/vaayne/mori)

### Con Beta

- GitHub：<https://github.com/nowledge-co/con-terminal>
- 介绍：基于 Ghostty 和 GPUI 的开源终端，目前仍处于 Beta 阶段。

### Zap

- 官网：<https://zap.zerx.dev/>
- GitHub：<https://github.com/zerx-lab/zap>
- 介绍：由 Warp 衍生而来的本地优先开源终端，可接入自定义模型服务和多种 CLI Agent。

### Warp

- 官网：<https://www.warp.dev/>
- GitHub：<https://github.com/warpdotdev/warp>
- 介绍：从终端发展而来的 Agent 开发环境，支持内置 Agent 和第三方 CLI Agent。

### Netcatty

- 官网：<https://netcatty.app/>
- GitHub：<https://github.com/binaricat/Netcatty>
- 介绍：集 SSH、SFTP 和终端管理于一体的跨平台工具。

> 使用体验：总的来说我还是很喜欢的，有几个原因：
>
> 1. 可以把特定命令保存为快捷操作。
> 2. 分屏时可以同时向多个面板发送相同的命令。
> 3. AI 集成也不错。

### Otty

- 官网：<https://otty.sh/>
- 介绍：介于传统终端和 Agent 开发环境之间的原生 macOS 终端。

## Agent 管理工具

### Orca

- 官网：<https://www.onorca.dev/>
- GitHub：<https://github.com/stablyai/orca>
- 介绍：用于并行运行和管理多个编码 Agent 的开源 Agent 开发环境，支持桌面端和移动端。

### Cindy

- 官网：<https://www.cindy.app/>
- GitHub：<https://github.com/makecindy/cindy>
- 介绍：本地优先的开源 AI Agent，支持 Claude Code、Codex 和 Pi，并提供桌面端与移动端。

> 使用体验：图标和官网都符合我的审美，整体体验一般。
>
> 不太好的一点是会强制更新；不更新就无法继续使用。

### WorkBuddy

- 官网：<https://www.workbuddy.ai/>
- 介绍：腾讯推出的通用型 AI Agent，可以处理文档、研究、演示文稿和开发任务，并支持从手机端远程控制电脑上的任务。

> 使用体验：我只用它写微信公众号文章，做一些简单的东西还可以。

### TraeWork

- 官网：<https://www.trae.ai/work>
- 介绍：面向日常工作的 AI 助手，支持文档、演示文稿、数据分析、研究和开发任务，可在桌面端、网页端和移动端使用。

### Paseo

- 官网：<https://paseo.sh/>
- GitHub：<https://github.com/getpaseo/paseo>
- 介绍：自托管、支持多种 Agent 的开源控制平台，提供桌面端、网页端、移动端和 CLI。

## 编辑器

### Zed 与 Zed Preview

- 官网：<https://zed.dev/>
- GitHub：<https://github.com/zed-industries/zed>
- 介绍：高性能、支持多人协作的开源代码编辑器；Zed Preview 用于提前体验新功能。

### Visual Studio Code 与 Visual Studio Code Insiders

- 官网：<https://code.visualstudio.com/>
- GitHub：<https://github.com/microsoft/vscode>
- Insiders：<https://code.visualstudio.com/insiders/>
- 介绍：Visual Studio Code Insiders 是每日更新的预览版本，可以更早体验新功能和修复。

## Token 记录

### TokenTracker

- GitHub：<https://github.com/xiufengsun/TokenTracker>
- 介绍：本地优先的 AI Token 用量和成本统计工具，提供 macOS 菜单栏应用。

> 使用体验：好看。

### CodeBurn

- GitHub：<https://github.com/getagentseal/codeburn>
