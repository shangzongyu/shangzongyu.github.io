之前用 MonitorControl，现在改用 BetterDisplay。

## 主要功能

- HiDPI 缩放和分辨率控制
- 亮度和音量控制 (DDC/CI)
- 虚拟显示器
- 颜色配置文件切换
- 显示旋转和镜像
- XDR/HDR 亮度增强
- 多显示器同步

## 安装

```bash
brew install --cask betterdisplay
```
